# CareerAI – AI-Powered Job & Interview Intelligence Platform

CareerAI is an AI-powered career assistance platform that helps job seekers analyse their resumes, match themselves with job descriptions, prepare for interviews, identify skill gaps, and create personalised career recommendations.

## 🚀 Features

- 📄 AI Resume Analysis
- 🎯 Job Description Matching
- 🤖 AI Interview Question Generation
- 📝 Interview Answer Evaluation
- 📊 Interview Progress Tracking
- 🧠 Skill Gap Analysis
- 🗺️ Career Roadmap Generation
- 💼 AI Job Recommendations
- ✨ Resume Improvement Suggestions
- 📑 AI Career Report
- 📈 Career Readiness Score

## 🛠️ Technologies Used

### Frontend
- HTML5
- CSS3
- JavaScript
- LocalStorage

### Backend
- Python
- FastAPI
- REST APIs

### AI
- Google Gemini API
- Large Language Model (LLM)
- Prompt Engineering
